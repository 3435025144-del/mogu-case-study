# MOGU 馋伴产品案例网站

## 预览

直接双击 `index.html` 即可浏览，不需要安装依赖或启动服务器。

页面已适配：

- 1440px 桌面
- 768px 平板
- 390px 手机

## 页面结构

1. 案例封面：让每一次没做到，都还有下一次
2. 情境代入与产品出现
3. 团队最初的用户流程假设
4. 小 A 的真实用户旅程
5. 用户为什么放弃
6. 三次问题重构
7. 三次关键设计判断
8. 最终产品功能拆解
9. 可用性测试、已验证结论与下一轮假设

## 数据说明

- 6 份前期访谈、5 位可用性测试参与者来自现有研究资料。
- 90% 有减重或健康管理意愿、70% 中途放弃，使用团队前期问卷与访谈综合口径。
- 88.37%、51.16%、34.88% 来自现有问卷结果图。
- 网站没有新增虚构的业务增长、留存率或满意度数据。

正式发布前建议再次确认问卷样本量与 90%/70% 对应的原始题目，确保研究口径完全一致。
